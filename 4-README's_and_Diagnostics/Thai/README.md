# PoE2 Route AutoSplitter

เครื่องมือสำหรับตั้งค่าและ autosplitter ของ LiveSplit สำหรับ **การ speedrun แคมเปญของ Path of Exile 2**

เวอร์ชันปัจจุบัน: **v3.0.0 Release Candidate**

PoE2 Route AutoSplitter มีเส้นทางแบบสำเร็จรูปและแบบกำหนดเองสำหรับ:

* การสำรวจ / การจบพื้นที่
* Boss Rush
* การสำรวจ + Boss Rush แบบรวม
* Campaign Any%
* Campaign 100%
* เฉพาะบอสที่จำเป็นของแคมเปญ
* บอส Pinnacle 0.5
* Temple of Chaos
* Trial of the Sekhemas
* เส้นทางที่ผู้ใช้กำหนดเอง
* Maps

แอปพลิเคชัน **PoE2RouteSetup** ที่ให้มาด้วยจะจัดการขั้นตอนการตั้งค่าส่วนใหญ่ให้คุณ

สามารถหยุดเกมและตัวจับเวลาของ LiveSplit พร้อมกันเมื่อเปิดเมนูหยุดเกมได้
ตัวเลือก Game Time ของ LiveSplit จะตัดเวลาโหลดออก และจะหยุดตัวจับเวลาระหว่างการหยุดเกมด้วยเมื่อเปิดตัวเลือกที่เกี่ยวข้อง

# นโยบายการรัน

เครื่องมือนี้ถูกออกแบบให้ไม่ผูกกับกฎของการรันแบบใดแบบหนึ่งมากเกินไป ผู้เล่นจึงมีอิสระพอสมควรในการเลือกกฎและตัวกระตุ้นที่ต้องการใช้

สำหรับการเริ่มตัวละครใหม่ที่ Riverbank ช่วงสั้น ๆ ตั้งแต่ตัวละครตื่นจนถึงการคุยกับ The Wounded Man จะไม่ถูกจับเวลาโดยตั้งใจ เพื่อให้ผู้เล่นมีเวลาปรับการตั้งค่า เลือก “skip tutorial” หรือแก้ตัวเลือกอื่นก่อนเริ่มรันจริง หลังจากคุยกับ The Wounded Man เวลาเริ่มรันจะเริ่มที่ประโยคเปิดสุดท้ายของเขา

การเริ่มจากการเปลี่ยนโซนจะทำงานทันทีเมื่อผู้เล่นเข้าสู่โซนที่กำหนดไว้ สำหรับรันแบบไดนามิก ตัวจับเวลาและการติดตามจะเริ่มเมื่อเข้าสู่โซนนั้นเท่านั้น แม้ว่าจะเริ่มต้นอยู่ในโซนอื่นก็ตาม

เนื่องจากเกมมีความยาวมาก จึงมี GameTimeWatcher ซึ่งเป็นโปรแกรมขนาดเล็กที่สั่งให้ LiveSplit หยุด Game Time เมื่อเปิดเมนู Pause Game หรือเมนู microtransaction ฟังก์ชันนี้ช่วยให้ผู้เล่นพักหรือจัดการเรื่องอื่นที่ต้องใช้ความสนใจเต็มที่ได้ เมนูอื่นจะไม่หยุดเวลาเพราะผู้เล่นยังควบคุมตัวละครได้ เวลาในเกมยังเดินระหว่างคัตซีน เพราะยังสามารถเปิดอินเวนทอรีและใช้ช่วงนั้นจัดของเพื่อปรับปรุงการรันได้ ปัจจุบันตัวจับเวลาจะหยุดเฉพาะระหว่างหน้าจอโหลด เมนูหยุดเกม และร้าน microtransaction เท่านั้น

# การตั้งค่า LiveSplit

ต้องตั้งค่า 2 อย่างใน LiveSplit:

1. ไฟล์ splits (`.lss`)
2. Scriptable Auto Splitter (`.asl`)

## โหลดไฟล์ splits

ในโฟลเดอร์ **LiveSplit Target** ที่สร้างขึ้น ให้หาไฟล์ `.lss` แล้วเปิดด้วย LiveSplit

หรือโหลดด้วยตนเองจาก LiveSplit ผ่าน:

**File → Open Splits → From File**

เลือกไฟล์ `.lss` ที่สร้างไว้

---

## เพิ่ม Scriptable Auto Splitter

ต้องเพิ่มสคริปต์ autosplitter ลงใน layout ของ LiveSplit ด้วยตนเอง

ใน LiveSplit:

1. คลิกขวาที่ LiveSplit
2. เลือก **Edit Layout**
3. กดปุ่ม **+**
4. เลือก:

   **Control → Scriptable Auto Splitter**

5. เลือกคอมโพเนนต์ **Scriptable Auto Splitter** ที่เพิ่มใหม่
6. เลือกไฟล์ `.asl` ในโฟลเดอร์ **LiveSplit Target**
7. บันทึก layout

ต้องเปลี่ยน path นี้เฉพาะเมื่อย้ายไฟล์ที่สร้างขึ้น หรือเปลี่ยนไปใช้การตั้งค่าที่ใช้ไฟล์ ASL คนละไฟล์

> PoE2 Route AutoSplitter **ไม่**สร้างหรือแทนที่ layout ส่วนตัวของ LiveSplit

layout ยังคงอยู่ภายใต้การควบคุมของผู้ใช้

---

# การตั้งค่า Boss Rush

เส้นทางที่ติดตามบอสจะใช้โปรแกรม **BossWatcher** ที่ให้มาด้วย

BossWatcher อ่านชื่อบอสจากเกมและส่ง event ของบอสไปยัง autosplitter

หากเส้นทางที่เลือกต้องใช้ BossWatcher ให้กดปุ่ม:

**Start BossWatcher**

ใน PoE2 Route Setup

หน้าต่าง console จะเปิดขึ้น

ในการใช้งานปกติ BossWatcher จะแสดงเฉพาะ event ที่มีประโยชน์ เช่น:

* พบบอส
* กำจัดบอส
* ระยะเวลาการต่อสู้

ตัวอย่าง:

`[21:42:18] Encountered: The Executioner`

`[21:43:07] Defeated: The Executioner | Fight time: 49.213 s`

ระหว่างรันไม่จำเป็นต้องโต้ตอบกับ console ของ BossWatcher

ให้เปิดไว้ตลอด speedrun

# เส้นทางสำรวจ

เส้นทางสำรวจตรวจจับเมื่อผู้เล่นเข้าสู่พื้นที่ที่กำหนดใน Path of Exile 2

เส้นทางที่เป็นการสำรวจอย่างเดียว **ไม่ต้องใช้** BossWatcher

autosplitter จะอ่านข้อมูลการเปลี่ยนพื้นที่จาก Path of Exile 2 โดยอัตโนมัติ

# การสำรวจ + Boss Rush แบบรวม

เส้นทางแบบรวมจะติดตามทั้ง:

* การจบพื้นที่
* การกำจัดบอส

สำหรับเส้นทางเหล่านี้:

1. โหลด `.lss` ที่สร้างขึ้น
2. ตั้ง Scriptable Auto Splitter ให้ชี้ไปที่ `.asl` ที่สร้างขึ้น
3. เริ่ม BossWatcher จาก PoE2 Route Setup
4. เริ่มรัน

เป้าหมายของพื้นที่และบอสจะถูกจัดการโดยเส้นทางเดียวกัน

# Trials

ใช้สำหรับ Trial of the Sekhemas และ Temple of Chaos

เงื่อนไขเริ่มต้นคือเมื่อเข้าสู่ Trial จริงเป็นครั้งแรก พื้นที่โถงที่ใช้เตรียมตัวจะไม่ถูกติดตาม

มีเงื่อนไขจบ 2 แบบ:

1. เลือกว่าต้องการไปลึกแค่ไหนใน Trial เมื่อกำจัดบอสที่ระดับที่กำหนด Trial จะจบสำเร็จ หากไม่สามารถจบ Trial ได้ จะถือว่ารันล้มเหลวและต้องเริ่มใหม่ด้วยตนเอง

2. การออกจาก Trial จะถือว่าจบ ตัวเลือกนี้เหมาะสำหรับผู้ที่ต้องการใช้ออกจากสนาม Trial เป็นเงื่อนไขจบ ซึ่งหมายความว่าการเก็บของ, caches, ร้านค้า และการเลือก Ascendancy จะนับเป็นส่วนหนึ่งของรัน

# Maps

เวลาที่ใช้เตรียม Map จะไม่ถูกนับขณะอยู่ใน Hideout หรือ Map hub อื่น เมื่อเข้า Map ตัวจับเวลาจะเริ่มโดยอัตโนมัติ และจะ split เมื่อออกจาก Map ครั้งแรกหลังจากกำจัดบอสของพื้นที่แล้ว หากออกก่อนกำจัดบอส ตัวจับเวลาจะยังคงเดินต่อ ซึ่งทำให้สามารถรีบไปฆ่าบอส ออกจาก Map แล้วกลับเข้า Map เดิมเพื่อทำคอนเทนต์เพิ่มโดยใช้ตัวจับเวลาที่หยุดไว้ได้ (ดูนโยบายทางเลือกด้านล่าง)

Map run มีเงื่อนไขจบหลายแบบ:

* จำนวน Map ที่กำหนด
* จนเสียชีวิตครั้งแรก (Deathless Run)
* จบด้วยตนเอง
* กำจัด Pinnacle Boss ที่กำหนด

การติดตามการตายมี 3 ตัวเลือก:
* ไม่ติดตามการตาย
* เฉพาะการตายครั้งแรก
* ติดตามจำนวนการตาย

เมื่อเลือกการตายครั้งแรกหรือการติดตามการตาย ต้องกรอกชื่อตัวละครให้ตรงกับที่แสดงในเกมทุกตัวอักษร เพราะโปรแกรมจะอ่าน client logs เพื่อระบุการเสียชีวิตของตัวละคร

มีนโยบายการหยุดเวลา 2 แบบ:

* ใช้การกำจัดบอสเป็น event การจบ Map และ split จะจบเมื่อออกจาก Map ครั้งแรกหลังฆ่าบอส คล้ายกับนโยบายการจบ Map ของ PoE2
* นโยบายทางเลือก: ตัวจับเวลาจะหยุดเฉพาะระหว่างหน้าจอโหลด การหยุดเกมด้วยตนเอง หรือเมนู microtransaction (หากเปิดใช้) เวลาอื่นทั้งหมดจะยังเดิน รวมถึงการเตรียม Map การจัดอินเวนทอรี และการตรวจ loot

## BossWatcher split เร็วเกินไปหรือ split ตอนผู้เล่นตาย

BossWatcher จะบันทึกเมื่อแถบพลังชีวิตของบอสหายไปจากหน้าจอ ซึ่งอาจเกิดจากหลายสาเหตุ ผู้ใช้ต้องตัดสินเองว่า split นั้นถูกต้องหรือไม่ โดยค่าเริ่มต้นจะถือว่าบอสตายแล้วและทำ split หากเกิด split ทั้งที่ยังไม่จบบอส สามารถ undo split เพื่อย้อน LiveSplit กลับไปสถานะก่อนหน้า แล้วลองบอสอีกครั้งโดยใช้เวลาปัจจุบัน ปุ่มลัด undo split อยู่ใน settings ของ LiveSplit

# ไฟล์ที่สร้างสำหรับ LiveSplit

ตามเส้นทางที่เลือก **LiveSplit Target** อาจมี:

### `.lss`

รายการ splits ของ LiveSplit

### `.asl`

สคริปต์ autosplitter ที่ใช้โดยคอมโพเนนต์ Scriptable Auto Splitter ของ LiveSplit

### ไฟล์เส้นทาง/การตั้งค่า

ใช้บอก autosplitter ว่าพื้นที่และ/หรือบอสใดอยู่ในเส้นทางที่เลือก

### ไฟล์ event ของบอส

ใช้โดย BossWatcher และ autosplitter ที่รองรับบอส

อย่าแก้ไขไฟล์เหล่านี้ด้วยตนเอง เว้นแต่คุณเข้าใจสิ่งที่กำลังเปลี่ยน

ในการใช้งานปกติ ให้สร้างผ่าน **PoE2 Route Setup**

# สำคัญ

PoE2 Route AutoSplitter **ไม่**ควบคุมหรือแทนที่ layout ส่วนตัวของ LiveSplit

ผู้ใช้เป็นผู้จัดการเองสำหรับ:

* รูปลักษณ์ของตัวจับเวลา
* สีของ splits
* ฟอนต์
* ขนาดหน้าต่าง
* การตั้งค่า comparison
* คอมโพเนนต์ LiveSplit อื่น ๆ

PoE2 Route AutoSplitter ให้เฉพาะ splits ของเส้นทางและการตั้งค่า autosplitter

เมื่อรายงานปัญหา โปรดระบุ:

ข้อมูลเหล่านี้ช่วยให้สามารถทำซ้ำและแก้ไขปัญหาได้ง่ายขึ้นมาก

# การตรวจสอบแพ็กเกจและ Diagnostics

manifest SHA-256 สำหรับตรวจสอบไฟล์ release/runtime อยู่ใน:

`3 - verification files`

ไฟล์ manifest สำหรับตรวจสอบการตั้งค่า, manifest SHA-256 ของแต่ละ run, audit log และสรุป run ที่อ่านได้จะถูกเก็บไว้ในโฟลเดอร์นี้ด้วย ไฟล์เหล่านี้อยู่นอก `LiveSplit Target` ดังนั้นการสร้างเส้นทางใหม่จะไม่ลบไฟล์ audit ของ run ก่อนหน้า

log สำหรับ diagnostics ของ SetupUI, BossWatcher และ GameTimeWatcher จะถูกรวมไว้ที่:

`4-README's_and_Diagnostics\Diagnostics`

ภาพ PNG สำหรับ diagnostics จะบันทึกไว้ที่:

`4-README's_and_Diagnostics\Diagnostics\images`
