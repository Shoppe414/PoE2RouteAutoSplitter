# PoE2 Route AutoSplitter

Инструмент настройки и автосплиттер LiveSplit для **спидранов кампании Path of Exile 2**.

Текущая версия: **v3.0.0 Release Candidate**.

PoE2 Route AutoSplitter предоставляет готовые и пользовательские маршруты для:

* Исследования / завершения областей
* Boss Rush
* Комбинированного режима «Исследование + Boss Rush»
* Campaign Any%
* Campaign 100%
* Только обязательных боссов кампании
* Боссов Pinnacle 0.5
* Temple of Chaos
* Trial of the Sekhemas
* Пользовательских маршрутов
* Maps

Входящее в комплект приложение **PoE2RouteSetup** выполняет большую часть настройки.

При открытии меню паузы можно синхронно приостанавливать игру и таймер LiveSplit.
Опция Game Time в LiveSplit исключает время загрузок и, если соответствующая настройка включена, время ручной паузы.

# Правила забега

Я постарался сделать инструмент максимально независимым от конкретного набора правил. Игроки могут достаточно свободно выбирать правила забега и нужные триггеры.

При новом старте в Riverbank короткий промежуток между пробуждением персонажа и разговором с The Wounded Man намеренно не учитывается. Это даёт время исправить настройки, выбрать «skip tutorial» или изменить другие параметры до фактического начала забега. После взаимодействия с The Wounded Man таймер запускается на его последней вступительной реплике.

Старт по переходу в зону срабатывает сразу после входа персонажа в заранее выбранную зону. В динамических забегах таймер и отслеживание начинаются только после входа именно в эту зону, даже если забег был начат в другой зоне.

Из-за большой продолжительности игры был разработан GameTimeWatcher — простая программа, которая просит LiveSplit приостанавливать Game Time, пока открыто меню Pause Game или меню микротранзакций. Это позволяет делать перерывы или решать ситуации, требующие полного внимания. Другие меню не останавливают таймер, поскольку в них сохраняется управление персонажем. Во внутриигровых сценах таймер также продолжает идти, так как инвентарь остаётся доступным и может использоваться для оптимизации забега. Сейчас таймер приостанавливается только во время загрузок, в меню паузы и в магазине микротранзакций.

# Быстрый старт

## 1. Установите PoE2 Route AutoSplitter

Запустите:

`PoE2RouteAutoSplitter-vX.X.X-Setup.exe`

Следуйте инструкциям установщика.

После установки откройте:

**PoE2 Route AutoSplitter**

Запустится приложение настройки маршрута.

---

## 2. Выберите маршрут

Приложение Setup содержит список готовых маршрутов.

Выберите нужный маршрут.

Примеры:

* Campaign Any%
* Campaign 100%
* Только обязательные боссы
* Маршруты исследования
* Маршруты Boss Rush
* Комбинированные маршруты «Исследование + Boss Rush»

Можно также выбрать **Custom Route** и создать собственный маршрут.

---

## 3. Создайте конфигурацию LiveSplit

После выбора маршрута нажмите кнопку Generate.

Приложение создаст необходимые файлы в каталоге:

`LiveSplit Target`

В этой папке находятся файлы, необходимые LiveSplit для выбранного маршрута.

Содержимое **LiveSplit Target** заменяется при каждом создании новой конфигурации.

---

# Настройка LiveSplit

В LiveSplit нужно настроить два элемента:

1. Файл сплитов (`.lss`)
2. Scriptable Auto Splitter (`.asl`)

## Загрузка файла сплитов

В созданной папке **LiveSplit Target** найдите файл `.lss` и откройте его в LiveSplit.

Также его можно загрузить вручную через:

**File → Open Splits → From File**

Выберите созданный файл `.lss`.

---

## Добавление Scriptable Auto Splitter

Скрипт автосплиттера необходимо вручную добавить в макет LiveSplit.

В LiveSplit:

1. Щёлкните правой кнопкой мыши по LiveSplit.
2. Выберите **Edit Layout**.
3. Нажмите **+**.
4. Выберите:

   **Control → Scriptable Auto Splitter**

5. Выберите новый компонент **Scriptable Auto Splitter**.
6. Укажите файл `.asl` из папки **LiveSplit Target**.
7. Сохраните макет.

Менять этот путь нужно только при перемещении созданных файлов или переходе на конфигурацию с другим ASL-файлом.

> PoE2 Route AutoSplitter **не** создаёт и не заменяет ваш личный макет LiveSplit.

Макет остаётся под вашим контролем.

# Настройка Boss Rush

Маршруты с отслеживанием боссов используют программу **BossWatcher** из комплекта.

BossWatcher считывает имена боссов из игры и отправляет события боссов автосплиттеру.

Если выбранному маршруту нужен BossWatcher, используйте в PoE2 Route Setup кнопку:

**Start BossWatcher**

Откроется окно консоли.

В обычном режиме BossWatcher показывает только полезные события, например:

* Босс обнаружен
* Босс побеждён
* Длительность боя

Пример:

`[21:42:18] Encountered: The Executioner`

`[21:43:07] Defeated: The Executioner | Fight time: 49.213 s`

Во время забега взаимодействовать с консолью BossWatcher не требуется.

Оставьте её открытой во время спидрана.

# Маршруты исследования

Маршруты исследования определяют вход персонажа в заданные области Path of Exile 2.

Для маршрутов только с исследованием BossWatcher **не требуется**.

Автосплиттер автоматически читает информацию о переходах между областями Path of Exile 2.

---

# Исследование + Boss Rush

Комбинированные маршруты отслеживают:

* Завершение областей
* Победы над боссами

Для таких маршрутов:

1. Загрузите созданный `.lss`.
2. Укажите созданный `.asl` в Scriptable Auto Splitter.
3. Запустите BossWatcher из PoE2 Route Setup.
4. Начните забег.

Цели по областям и боссам будут обрабатываться одним маршрутом.

---

# Пользовательские маршруты

Выберите **Custom Route** в PoE2 Route Setup, чтобы создать собственный маршрут.

Можно включить:

* Области
* Боссов
* И области, и боссов

Добавьте нужные цели и расположите их в желаемом порядке.

После этого создайте конфигурацию.

Приложение создаст в **LiveSplit Target**:

* `.lss`
* `.asl`
* Конфигурацию маршрута

Загрузите их по тем же инструкциям LiveSplit, что приведены выше.

# Испытания

Предназначено для Trial of the Sekhemas и Temple of Chaos.

Условие старта — первый вход непосредственно в испытание. Фойе, где выполняется подготовка, не отслеживается.

Есть два условия завершения:

1. Вы выбираете глубину, до которой хотите пройти испытание. После убийства босса на заданной глубине испытание успешно завершается. Невыполненное испытание считается неудачным забегом и требует ручного перезапуска.

2. Выход из испытания отмечает его завершённым. Этот вариант подходит тем, кто хочет считать выход из арены конечным условием. Тогда сбор добычи, тайников, использование торговца и выбор Ascendancy входят во время забега.

---

# Vaal Ruins

Фойе считается граничной зоной для корректной обработки переходов. Поэтому вход в комнату с консолью из Map считается выходом из Map, а не входом в её подобласть.

Vaal Ruins всё ещё находятся в разработке.

---

# Maps

Подготовка Map не учитывается по времени, пока игрок находится в Hideout или другом центре Maps. При входе в Map таймер запускается автоматически, а сплит происходит при первом выходе после победы над боссом области. Если выйти до убийства босса, таймер продолжит идти. Это позволяет быстро убить босса, выйти, затем снова войти в ту же Map и проходить дополнительный контент при остановленном таймере. (Альтернативная политика описана ниже.)

Для забегов по Maps доступны несколько условий окончания:

* Фиксированное количество Maps
* До первой смерти (Deathless Run)
* Ручное завершение
* Победа над конкретным Pinnacle-боссом

Отслеживание смертей имеет три режима:
* Не отслеживать смерти
* Только первая смерть
* Отслеживать смерти

При выборе первой смерти или отслеживания смертей необходимо ввести имя персонажа точно так, как оно отображается в игре. Программа читает клиентские журналы, чтобы определить смерть персонажа.

Есть две политики паузы:

* Победа над боссом считается событием завершения Map, а сплит заканчивается при первом выходе после победы. Это похоже на политику завершения Maps в PoE2.
* Альтернативная политика: таймер приостанавливается только во время загрузок, ручной паузы или в меню микротранзакций (если включено). Во всё остальное время, включая подготовку Map, управление инвентарём и разбор добычи, таймер идёт.

# Смена маршрута

Чтобы перейти на другой маршрут:

1. Откройте PoE2 Route Setup.
2. Выберите новый маршрут.
3. Снова создайте конфигурацию.
4. Откройте новый `.lss` в LiveSplit.
5. Убедитесь, что Scriptable Auto Splitter указывает на `.asl` в **LiveSplit Target**.
6. Запустите BossWatcher, если новый маршрут требует обнаружения боссов.

Предыдущее содержимое **LiveSplit Target** будет заменено.

1. Запустите Path of Exile 2.

4. Убедитесь, что Scriptable Auto Splitter использует правильный `.asl`.
5. Запустите BossWatcher, если маршрут использует боссов.
6. Начните забег.

Автосплиттер автоматически обработает настроенные цели маршрута.

# Устранение неполадок

## Сплиты не срабатывают на боссах

Проверьте:

* BossWatcher запущен.
* BossWatcher был запущен из PoE2 Route Setup.
* Выбранный маршрут действительно содержит цели по боссам.
* Scriptable Auto Splitter LiveSplit указывает на созданный `.asl`.

---

## Сплиты не срабатывают на областях

Проверьте:

* Path of Exile 2 запущен.
* Scriptable Auto Splitter LiveSplit указывает на правильный `.asl`.
* Создан правильный маршрут исследования.
* Загружен правильный `.lss`.

---

## LiveSplit открывает неправильные splits

Откройте `.lss` напрямую из:

`LiveSplit Target`

или используйте:

**File → Open Splits → From File**

---

## После смены маршрута что-то перестало работать

Снова создайте новый маршрут и проверьте:

* Загружен правильный `.lss`.
* Scriptable Auto Splitter указывает на текущий `.asl` в **LiveSplit Target**.

---

## BossWatcher показывает ошибку

Закройте BossWatcher и снова запустите его кнопкой **Start BossWatcher** в PoE2 Route Setup.

Если проблема сохраняется, приложите показанную ошибку к сообщению о проблеме.

---
## BossWatcher сделал сплит слишком рано или при смерти игрока

BossWatcher регистрирует исчезновение полосы здоровья босса с экрана. Это может произойти по разным причинам. Пользователь должен сам определить, корректен ли сплит. По умолчанию предполагается, что босс умер, и выполняется сплит. Если сплит произошёл без завершения боя, отмена split возвращает LiveSplit в предыдущее состояние и позволяет повторить босса с текущего времени. Горячая клавиша отмены split находится в настройках LiveSplit.

# Файлы, создаваемые для LiveSplit

В зависимости от выбранного маршрута **LiveSplit Target** может содержать:

### `.lss`

Список сплитов LiveSplit.

### `.asl`

Скрипт автосплиттера, используемый компонентом Scriptable Auto Splitter в LiveSplit.

### Файлы маршрута/конфигурации

Они сообщают автосплиттеру, какие области и/или боссы входят в выбранный маршрут.

### Файлы событий боссов

Используются BossWatcher и автосплиттерами с поддержкой боссов.

Не редактируйте эти файлы вручную, если не уверены в своих действиях.

Для обычной работы создавайте их через **PoE2 Route Setup**.

---

# Важно

PoE2 Route AutoSplitter **не** управляет и не заменяет ваш личный макет LiveSplit.

Вы самостоятельно отвечаете за:

* Внешний вид таймера
* Цвета сплитов
* Шрифты
* Размер окна
* Настройки сравнений
* Другие компоненты LiveSplit

PoE2 Route AutoSplitter предоставляет только сплиты маршрута и конфигурацию автосплиттера.

# Проверка пакета и диагностика

SHA-256-манифесты для проверки файлов релиза или runtime находятся в:

`3 - verification files`

Там же хранятся манифесты проверки настройки, SHA-256-манифесты отдельных забегов, журналы аудита и читаемые сводки забегов. Они находятся вне `LiveSplit Target`, поэтому создание нового маршрута не удаляет файлы аудита предыдущих забегов.

Диагностические журналы SetupUI, BossWatcher и GameTimeWatcher централизованно сохраняются в:

`4-README's_and_Diagnostics\Diagnostics`

Диагностические PNG-снимки сохраняются в:

`4-README's_and_Diagnostics\Diagnostics\images`
