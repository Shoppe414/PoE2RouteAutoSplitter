PoE2 Route AutoSplitter v2.1.3

SOURCE REPOSITORY NOTE
----------------------
This folder intentionally does not contain compiled executables in Git.
Large release binaries are generated by the release build and published as
GitHub Release assets instead of being committed to the repository.

For normal users:
  Download PoE2AS-v2.1.3-Setup.exe from the GitHub Release.
  Run the installer. No PowerShell, .NET SDK, or compilation is required.

For developers building locally:
  Run 2 - Support Files\Build-Release.ps1
  The generated installer is copied into this folder and is ignored by Git.

The installed application keeps the familiar runtime structure:
  1 - User Setup\PoE2RouteSetup.exe
  1 - User Setup\LiveSplit Target\
  2 - Support Files\...

IMPORTANT LIVESPLIT SETUP REMINDERS
-----------------------------------
After generating a setup, open the generated .lss in LiveSplit and attach the
generated .asl to a Scriptable Auto Splitter component. LiveSplit does not
attach the .asl automatically.

If you want loading screens and, when enabled, manual-pause time excluded from
the displayed run time, set LiveSplit to Game Time. Real Time continues counting
those periods.

Premade route selection
-----------------------
The Premade setups tab now uses three compact controls:
  1. Mode: Area Completion, Boss Completion, Area + Boss Completion, or Level Race
  2. Setup: Campaign 100% / Any%, Act, Interlude, Combination, or Pinnacle where applicable
  3. Route order: Ordered or Dynamic / unordered

Sekhemas and Chaos are separate opt-ins below those selectors. Enable only the trial
content you want counted in the run. Ordered area/boss modes also let you choose the
objective immediately before the trial block; dynamic modes simply add the selected
trial objectives to the completion pool. Floors 3-4 of Sekhemas are not added unless
you explicitly select them.

Game Time
---------
Load-removed Game Time is handled directly by each deployed ASL using Path of
Exile 2 Client.txt [LOADING SCREEN] duration records.

GameTimeWatcher is optional. Enable it in the Setup UI only if you also want
LiveSplit Game Time to pause while PoE2 is manually paused in the GAME PAUSED
menu or Microtransaction Shop.

Campaign start
--------------
For campaign setups that start in The Riverbank, the timer begins on the
Wounded Man's final opening Client.txt line ("Reach... Clearfell... Find the
Miller..."). The new-character wake-up/setup window and first NPC interaction
are intentionally before the timed attempt.

IMPORTANT FOR MANUAL-PAUSE UPDATES
After updating GameTimeWatcher/manual-pause support, run PoE2RouteSetup again and reselect the newly generated .asl in LiveSplit's Scriptable Auto Splitter component. Rebuilding GameTimeWatcher alone does not update the ASL protocol.
