PoE2 BossWatcher v0.3.3 - Map Boss Database / 5.5 s Grace Static Validation
==========================================================================

Development validation date: 2026-08-17

New v0.3.3 checks:
- Default identity single-boss DisappearConfirmMs is 5500 ms.
- Default map MapDisappearConfirmMs is 5500 ms for both single and dual map-objective layouts. It remains separately user-configurable as BossWatcher.MapGoneConfirmMs for field testing.
- Existing identity dual-lane resolver defaults remain DualRemovalConfirmMs=350 ms and DualBothGoneConfirmMs=700 ms. They remain topology-specific because the current identity dual resolver shares one firstMissing timestamp; extending those values requires a per-lane timestamp refactor to preserve per-boss backdating.
- Added versioned `map-bosses.json` and database-preferred map-boss OCR identity gating.
- Deterministic map entries must OCR-match the expected completion boss before MAP_SEEN/MAP_GONE can arm/qualify the map.
- A nonmatching boss in a deterministic map is ignored and logged as MAP_UNEXPECTED_BOSS_IGNORED; known event-boss identities can be labeled MAP_EVENT_BOSS_IGNORED.
- Unknown/special/random-boss maps retain structural fallback during development and emit MAP_DATABASE_MISS / MAP_DATABASE_SPECIAL diagnostics.
- SetupUI snapshots the exact database to `LiveSplit Target\poe2_map_bosses.json`; BossWatcher accepts `--map-db <path>` and SetupUI launches it against that generated copy.
- `poe2_run_settings.json` records the database version and SHA-256; both the settings snapshot and generated database snapshot are covered by the setup SHA-256 manifest.
- `--settings <path>` continues to read BossWatcher.GoneConfirmMs and BossWatcher.MapGoneConfirmMs from the generated poe2_run_settings.json snapshot.
- Existing firstMissing backdating remains unchanged: GONE confirmation is delayed, but recorded completion time remains the first valid missing signal.
- Missing-window cancellation / RETURNED behavior remains armed throughout the grace period.
- All 14 base ASL templates are byte-identical to the preceding shared-settings development build; map policy changes are injected by SetupUI at generation time.
- GameTimeWatcher is byte-identical to the preceding shared-settings development build.
- No Windows/.NET compilation was attempted in this environment, per project test workflow; rebuild and live validation are performed by the user on Windows.
