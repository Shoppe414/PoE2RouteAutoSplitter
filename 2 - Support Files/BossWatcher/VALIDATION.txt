PoE2 BossWatcher v0.3.1 - Validation
============================================================

Validation date: 2026-08-14

Windows compile hotfix (2026-08-16):
- BossContextReader constructor now explicitly calls `System.IO.Path.GetFullPath(path)` because the class also exposes a `Path` property; the unqualified `Path.GetFullPath` bound to that string property and caused CS1061 during dotnet publish.
- No map-context, OCR, structural boss detection, timing, or event semantics changed.

Static map-context validation (2026-08-15):
- Program version is 0.3.1-map-context.
- `--context-file` selects identity/map/off modes; missing/transient context reads preserve the last good state.
- GenericMapBossTracker contains no OcrService, BossNameMatcher, boss-ID lookup, or BossNameTemplate use.
- Map acquisition uses BossBarMetrics structural health red-run + gold UI-band thresholds.
- MAP_SEEN / MAP_GONE events include area, areaLevel, mapBossNumber, classification, and layout.
- Dual map UI does not complete when only one lane disappears; full UI disappearance is required.
- Existing identity tracker and 85-entry OCR catalog remain present for campaign/trial/Pinnacle identity events.
- Windows/.NET compilation is not available in this validation environment; the user must rebuild with Build-Release.ps1.

Static validation passed for the v0.3.1 build-path hotfix and retained v0.3.0 user-console behavior:
- Catalog contains 85 OCR identities after adding the missing optional Sekhemas/Chaos trial bosses.
- Campaign 100 remains 67 bosses and includes Beira of the Rotten Pack.
- Existing Campaign 100 / Required Bosses / Pinnacle target files are unchanged by the optional trial catalog expansion.
- Rattlecage, Hadi, Rafiq, Ashar, Uxmal, Chetza, and Bahlak are present in bosses.txt.
- The captured OCR sample `WE RATTLECAGE THE EARTHEREAKER NS` now ranks Rattlecage at ~0.960 similarity versus the previous false Rathbreaker candidate at ~0.818 under the unchanged matcher algorithm.
- Zarokh and The Trialmaster remain present under the trial catalog grouping and retain their existing IDs used by pinnacle targets.
- Required Bosses Only baseline is 40 bosses and excludes The Rotten Druid and Diamora, Song of Death.
- Beira is absent from excluded-unstable-minibosses.
- --dev-console / --dev are accepted as developer-console flags.
- Per-frame diagnostic console output is gated behind developer mode.
- Normal console emits timestamped encounter events.
- Normal console emits timestamped defeat events and fight duration in seconds.
- Fight duration ends at firstMissing, the same backdated disappearance point used for boss split timing.
- Boss-return diagnostics remain in the event/debug stream but are hidden from the normal user console.
- --event-file allows the setup UI to direct the boss event log into the active target directory.
- Build.ps1 uses `Test-Path -LiteralPath` for tessdata validation and `Copy-Item -LiteralPath` for bracket-safe source copies.

BUILD / RUNTIME LIMITATION
--------------------------
No .NET SDK/compiler or PowerShell runtime is installed in the validation environment, so the Windows project was not compiled or live-tested here.
Use Setup-OCR.ps1 and Build.ps1 on Windows with .NET 10 SDK to publish the executable, then perform an in-game verification pass.
