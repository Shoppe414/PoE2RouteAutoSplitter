PATH OF EXILE 2 ROUTE AUTOSPLITTER v1.4.0

NORMAL USER SETUP

1. Open:
   2 - Support Files\Setup UI [Configuration]

2. Run:
   .\Build.ps1

   This creates/copies:
   1 - User Setup\PoE2RouteSetup.exe

   and ensures this folder exists:
   1 - User Setup\LiveSplit Target

3. If you will use Boss Rush or mixed Exploration + Boss Rush modes, build BossWatcher:
   2 - Support Files\BossWatcher [Boss Rush Detection]\Setup-OCR.ps1   (only if OCR data is missing)
   2 - Support Files\BossWatcher [Boss Rush Detection]\Build.ps1

4. Launch:
   1 - User Setup\PoE2RouteSetup.exe

5. Select a premade route or create a custom route and press Generate / Deploy Selected Setup.

6. Open the generated .lss from:
   1 - User Setup\LiveSplit Target

7. Use your own LiveSplit layout. Add/edit its Scriptable Auto Splitter component and point it to the generated .asl in LiveSplit Target.

8. For boss-enabled modes, press Start BossWatcher in the Setup UI.

No .lsl layout file is generated or included.
